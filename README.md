# Event-Pro-Mobile

Event-Pro-Mobile is a mobile application built with Expo Router and React Native for discovering and managing events.

## Features
- Browse upcoming events
- View event details
- Register for events
- Event notifications
- User profile management

## Tech Stack
- React Native
- Expo
- Expo Router
- JavaScript

## Getting Started

Install dependencies:

npm install

Start the development server:

npx expo start

Run on Android:

npm run android

Run on Web:

npm run web

## Team Workflow

Developers should create feature branches from the `develop` branch.

Example:

git checkout develop  
git checkout -b feature/event-list
